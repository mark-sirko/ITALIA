# Як опублікувати застосунок на GitHub Pages

Публічна версія — БЕЗ фінансів (тільки огляд, маршрут, виїзди, багаж).
Приватну версію з грошима (файл «Сицілія_застосунок.html») НЕ викладай — тримай офлайн у себе.

## Шлях без ноута (з телефона або браузера)

1. Зайди на github.com, увійди / зареєструйся (безкоштовно).
2. Праворуч угорі «+» → **New repository**.
   - Repository name: наприклад `trip` (це буде в адресі).
   - Public. Натисни **Create repository**.
3. На сторінці репозиторію: **Add file → Upload files**.
   - Перетягни ВСІ файли з цієї теки (крім цього md і крім приватного файлу з грошима):
     index.html, manifest.webmanifest, sw.js,
     icon-192.png, icon-512.png, icon-180.png, icon-512-maskable.png
   - Унизу **Commit changes**.
4. **Settings** (угорі) → зліва **Pages**.
   - Source: **Deploy from a branch**.
   - Branch: **main**, тека: **/ (root)** → **Save**.
5. Зачекай ~1 хв, онови сторінку Pages. З'явиться адреса виду:
   `https://ТВІЙ-НІК.github.io/trip/`
   Відкрий її — це вже живий застосунок.

## Додати іконку на телефон (справжній PWA)

- **iPhone:** відкрий адресу В SAFARI (не Chrome!) →
  «Поділитися» → **На початковий екран**.
- **Android:** відкрий у Chrome → меню (⋮) →
  **Додати на головний екран / Встановити застосунок**.

Відкриється на весь екран, з іконкою, працює офлайн (service worker кешує все).

## Оновлення

Коли зміняться дані (заброньовані готелі тощо):
1. Дай мені знати — я віддам новий index.html.
2. У репозиторії: Add file → Upload files → заміни index.html → Commit.
3. У файлі sw.js зміни `sicily-trip-v1` на `-v2` (щоб кеш оновився), теж залий.
4. На телефоні відкрий застосунок — підтягне нову версію.

## Приватність

- Адреса Pages ПУБЛІЧНА: будь-хто з посиланням відкриє.
- Тому фінансів у цій версії немає.
- Приватну версію з грошима відкривай лише як локальний файл у себе.
